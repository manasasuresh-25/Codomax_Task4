# CodSoft Data Analytics Internship – Task 3

## Task
Data Visualization

## Objective
Create meaningful visualizations using Python libraries to identify trends, patterns, and insights from the cleaned Netflix dataset.

## Tools Used
- Python
- Jupyter Notebook/VS Code
- Pandas
- Matplotlib
- Seaborn

## Visualizations Created
- Bar Chart – Movies vs TV Shows
- Line Chart – Content Released by Year
- Pie Chart – Content Type Distribution
- Histogram – Release Year Distribution
- Scatter Plot – Release Year vs Content Type
- Bar Chart – Top 10 Countries
- Bar Chart – Top 10 Genres

## Key Insights
- Movies are more prevalent than TV Shows.
- Content releases increased significantly in recent years.
- The United States contributes the largest number of Netflix titles.
- Drama and International Movies are among the most frequent genres.
- Most content was released after 2015.



## Dashboard in PowerBI

An interactive dashboard was created using Power BI to visualize Netflix content. The dashboard includes:

- Total Titles
- Movies vs TV Shows
- Top 10 Countries
- Release Year Trend
- Genre Distribution
- Interactive Filters (Country, Type, Release Year)

The dashboard enables users to explore the dataset dynamically and gain meaningful insights.
